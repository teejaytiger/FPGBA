# FPGBA
## An overhaul of the original Gameboy Advance hardware! Features:
1. Simultaneous play + charging (USB-C)
2. FPGA JTAG headers for reprogramming
3. Modular design (Mainboard and daughter boards for the left and right controls)
4. Native support for IPS screens
5. Modern audio (no hiss!)
